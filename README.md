# NxtTrendz - E-Commerce Web Application

A responsive e-commerce application built using React.js with authentication, product listing, and cart management features.

## Tech Stack
- React.js
- JavaScript
- CSS
- React Router
- Context API

## Features
- User authentication with protected routes
- Product listing and details view
- Add to cart functionality
- Update product quantity dynamically
- Remove individual items from cart
- Remove all items from cart
- Cart summary with total price and item count
- Responsive UI design

# NxtTrendz - E-Commerce Web Application

NxtTrendz is a responsive e-commerce web application built using React.js. It allows users to browse products, view product details, and manage their shopping cart with real-time updates.

---

## 🚀 Features

- User authentication with login functionality
- Protected routes for secure navigation
- Product listing with categories and filters
- Product details page with similar products
- Add to cart functionality
- Update product quantity dynamically
- Remove individual items from cart
- Remove all items from cart
- Cart summary with total price and item count
- Empty cart view
- Responsive UI design
