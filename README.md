# NxtTrendz - E-Commerce Web Application

A responsive e-commerce application built using React.js with authentication, product listing, and cart management features.

## Tech Stack
- React.js
- JavaScript
- CSS
- React Router
- Context API

## Features
- User authentication with protected routes
- Product listing and details view
- Add to cart functionality
- Update product quantity dynamically
- Remove individual items from cart
- Remove all items from cart
- Cart summary with total price and item count
- Responsive UI design
